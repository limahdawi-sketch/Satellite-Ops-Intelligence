# Start here — Satellite Ops Intelligence v1.4.0

1. Extract the source ZIP into a new writable folder.
2. Open that folder in VS Code with File → Open Folder.
3. Run `npm run verify` in the integrated terminal.
4. Run `start-website.bat`, then open `http://localhost:8080`.
5. Review the new navy-sidebar / white-workspace theme and the bilingual Guided Learning walkthrough.
6. Confirm the training case values and test the lab buttons and report exports.
7. Follow `DEPLOY.md` for GitHub Pages/Netlify; then `LAUNCH_CHECKLIST_v1.4.0.md` for phone installation and LinkedIn.

The default light theme is intentionally high contrast; the theme toggle still enables dark mode. All example values are synthetic.
